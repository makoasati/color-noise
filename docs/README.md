# Color&Noise — Editorial Documentation

Two layers, in precedence order.

## 1. Standards — binding on every article

| File | What it covers |
|---|---|
| [editorial/ARTICLE-STANDARDS.md](editorial/ARTICLE-STANDARDS.md) | Required fields, title and slug rules, dates, excerpt, the 4-image minimum, body, links, fact-checking, typography, accessibility, the AI-artifact hard-fail list, and the pre-publish checklist |
| [editorial/BANNED.md](editorial/BANNED.md) | The prose ban list — constructions, words and phrases, and revision protocols |

## 2. Voice — one guide per byline

| File | Byline / category |
|---|---|
| [voice/README.md](voice/README.md) | Index, house rules, tell-them-apart test |
| [voice/jude-heard.md](voice/jude-heard.md) | Jude — Heard (live music) |
| [voice/julian-vane-seen.md](voice/julian-vane-seen.md) | Julian Vane — Seen (art and architecture) |
| [voice/mora-around.md](voice/mora-around.md) | Mora — Around (neighborhoods) |
| [voice/admin-seen.md](voice/admin-seen.md) | `admin` — Seen (one article; needs reassigning) |

**Precedence:** Article Standards → BANNED.md → voice guide. A voice signature never justifies breaking a standard or a ban.
